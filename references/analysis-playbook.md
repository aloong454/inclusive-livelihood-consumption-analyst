# 分析套路手册

> 五个可复用的分析模式。每个模式都给出“输入—步骤—输出句式—常见错误”。

## 模式 1：结构扫描

**回答的问题：** 钱花到哪里去了？基本生活压力有多重？

**输入：** 某群体某年八大类人均支出。

**步骤：**

1. 计算总消费和八大类占比；
2. 按占比从高到低排序，取前 3 类；
3. 计算刚性支出占比（食品+居住）；
4. 计算发展型支出占比（交通通信+教育文化娱乐+医疗保健）；
5. 与全国/城镇/同区域基准比较。

**输出句式：**

> 在[年份/区域/人群]口径下，[群体]的人均消费支出为[金额]元，其中[品类 A]和[品类 B]合计占[比例]%，刚性支出压力[高于/低于]对比基准[X]个百分点。教育文化娱乐占比为[比例]%，但增速为[比例]%，呈现“占比不高、增长较快”的特征。

**常见错误：**

- 只看占比，不看绝对量；
- 把“食品占比高”直接等同于“贫困”；
- 把自定义的“刚性支出”写成官方指标。

## 模式 2：变化追踪

**回答的问题：** 什么在变？变化有多大？是谁贡献的？

**输入：** 两个可比期间的八大类支出。

**步骤：**

1. 计算总支出增速（名义/实际）；
2. 计算各品类增速；
3. 计算各品类对总增长的贡献度；
4. 区分“占比变化”和“绝对量变化”；
5. 检查基期是否异常、口径是否变化。

**输出句式：**

> [年份]年[群体]人均消费支出同比增长[比例]%，其中[品类]增长[比例]%，对总增长贡献约[比例]%。[品类]占比[上升/下降][X]个百分点，但绝对支出[增加/减少][金额]元，说明[解释]。

**常见错误：**

- 把高增速当成高贡献；
- 把占比下降写成“支出下降”；
- 用环比解释年度变化；
- 忽略价格因素。

## 模式 3：群体分化

**回答的问题：** 谁不一样？差异在水平还是结构？

**输入：** 两个及以上群体的同口径数据。

**步骤：**

1. 对齐时间、区域、品类口径；
2. 比较人均支出水平（倍数/差额）；
3. 比较结构（百分点差异）；
4. 比较增速（谁在追赶/分化）；
5. 检查样本量和构成差异；
6. 把差异翻译成生活场景，而不是人格标签。

**输出句式：**

> [群体 A]的人均消费支出为[金额]元，是[群体 B]的[X]倍；结构上，[群体 A]的[品类]占比高[X]个百分点，主要对应[租房/通勤/子女教育]等场景。需要说明的是，两个群体的年龄、家庭结构和样本量不同，差异不能直接归因于消费观念。

**常见错误：**

- 把群体均值套到个人；
- 用“消费观念”解释一切；
- 忽略样本构成；
- 把差异写成“优劣”。

## 模式 4：场景识别

**回答的问题：** 这些数字对应什么真实生活？

**输入：** 品类结构 + 群体特征 + 地区背景。

**步骤：**

1. 从高占比/高增速品类出发；
2. 列出可能的生活场景（至少 2 种解释）；
3. 用其他数据交叉验证（通勤时长、房租、学龄子女、医保支出等）；
4. 排除“统计口径造成”的解释；
5. 输出“场景假设”，而不是“人群标签”。

**示例：**

| 数据信号 | 可能场景 | 需要验证 |
|---|---|---|
| 交通通信占比高、增速快 | 跨城/跨区通勤、网约车、手机换机 | 通勤距离、工作地、公共交通可达性 |
| 教育文化娱乐增速快 | 子女课外班、成人技能学习、文旅 | 家庭结构、学龄段、假期安排 |
| 居住占比高 | 租房、房贷、合租 | 租房/自有房、租金水平、家庭人口 |
| 医疗保健占比高 | 慢病用药、老人照护、体检 | 年龄结构、医保报销、家庭照护 |

**输出句式：**

> 这一结构更可能对应[场景 A]和[场景 B]两种解释。现有数据不足以区分二者，建议补充[数据]后再判断。

**常见错误：**

- 看到教育支出高就认定“重视教育”；
- 看到医疗支出高就推断“身体不好”；
- 把场景假设写成确定结论。

## 模式 5：产品适配

**回答的问题：** 对普惠金融产品有什么启示？哪些不能做？

**输入：** 结构、变化、分化、场景假设。

**步骤：**

1. 明确真实需求场景（通勤、租房、子女教育、慢病用药、家庭照护等）；
2. 判断需求周期（天/周/月/年）；
3. 判断金额量级（小额/中额）；
4. 评估还款来源与适当性；
5. 设计“产品假设”，而不是“授信结论”；
6. 列出风险、合规与人工复核要求；
7. 设计验证指标（用户测试、转化、逾期、投诉）。

**输出句式：**

> 基于[场景]的[周期/金额]特征，可考虑[小额/短周期/透明计费]的产品假设，但需先验证[还款来源/适当性/用户理解度]。不建议基于单一消费结构做泛化提额；所有个人层面的决策应由人工结合征信、收入、负债和反欺诈结果复核。

**常见错误：**

- 从“消费高”直接推“额度高”；
- 把“需求”当成“借款意愿”；
- 忽略综合资金成本；
- 不做用户测试就宣称有效。

## 模式 6：全球城市对比

**回答的问题：** 两个城市/国家能不能比？比结构还是比水平？结论能说到什么程度？

**输入：** 两个及以上城市/国家的同口径数据，含国家、币种、价格基准、分类、数据层级。

**步骤：**

1. 确认国家、城市/都市圈定义、数据层级（city/metro/national）；
2. 对齐分类（COICOP-13 / Global Core 8 / 本地分类），记录映射；
3. 确认币种与价格基准：名义本币、实际本币、PPP 国际元；
4. 如果跨币种，先转 PPP；如果只有名义本币，禁止水平排名；
5. 确认 CPI 基期、PPP 来源/年份；
6. 标注可比性等级 A/B/C；
7. 先比结构（占比），再比实际增速，最后才比 PPP 水平；
8. 写出至少一条不可比因素。

**输出句式：**

> 在[年份]、[分类]、[币种/PPP]口径下，[城市 A]与[城市 B]的食品+居住占比分别为[X]%和[Y]%。两国名义本币不能直接比较；按[PPP 来源/年份]折算后，[城市 A]的人均消费为[P]国际元，[城市 B]为[Q]国际元。可比性等级为[B]，只做方向性比较，不做精确排名。局限：[调查框架/年份/覆盖/非正规经济]。

**常见错误：**

- 用 €25,600 与 S$40,000 直接比较；
- 用国家级数据写城市名；
- 把中国八大类与 COICOP 直接拼接；
- 用市场汇率代替 PPP；
- 不标可比性等级就排名；
- 忽略估算租金、非正规经济、样本覆盖。

## 组合套路：一页纸分析

如果只有 10 分钟，按这个顺序讲：

1. **一句结论**：这个群体最大的结构特征是什么？
2. **一张结构图**：钱花在哪；
3. **一张变化图**：什么在变；
4. **一个分化点**：谁不一样；
5. **一个产品假设**：可以验证什么；
6. **一条边界**：不能做什么。

## 快速诊断表

| 现象 | 先检查 | 不要急着说 |
|---|---|---|
| 某品类占比突然上升 | 基期是否异常、口径是否变化 | “消费升级” |
| 总支出增长但品类普遍下降 | 人口/样本结构是否变化 | “大家更敢花钱了” |
| 城乡差距扩大 | 物价、人口迁移、样本构成 | “农村消费不行” |
| 教育支出增速高 | 基数、学龄人口、政策 | “教育焦虑” |
| 医疗支出增速低 | 医保报销、集采、年龄结构 | “健康水平提高” |
| 新市民消费低于城镇 | 收入、房租、家庭赡养 | “消费观念落后” |
| 跨国城市名义金额差距大 | 币种、PPP、分类、数据层级 | “A 国比 B 国富裕” |
| 城市数据只有全国平均 | 数据层级、城市子样本 | “这个城市就是这样” |
| 居住占比异常高/低 | 估算租金、自有房/租房结构 | “房价高/低” |
| 某城市教育占比高 | 分类映射、学制、公共/私人支出 | “更重视教育” |
