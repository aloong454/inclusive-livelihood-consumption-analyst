# 图表规范：饼图与柱形图

> 图表不是装饰。先确定“读者要比较什么”，再选图。

## 1. 选图规则

| 读者要回答的问题 | 用什么图 | 不要用什么 |
|---|---|---|
| 一个城市/群体的钱，按品类怎么分？ | **饼图**（≤7 类） | 8 类以上还硬塞饼图 |
| 不同年龄人群，谁占的消费比重更高？ | **柱形图**（横向或纵向） | 饼图（饼图不适合比较多个群体） |
| 不同年龄人群在品类上的结构差异？ | **分组柱形图** | 多张饼图并排 |
| 时间趋势 | 折线图 | 饼图 |
| 两个群体精确对比 | 条形图 + 差值标注 | 两个饼图靠肉眼比角度 |

**一句话：饼图回答“一个整体怎么分”，柱形图回答“谁高谁低”。**

## 2. 饼图规则

- 只用于 **part-to-whole**，且类别 ≤ 7；超过 7 类时合并为“其他”；
- 按占比从大到小排序；
- 每块必须标百分比；图例写清类别；
- 必须有“总计/分母”说明；
- 不要用 3D、爆炸效果、阴影；
- 不要用饼图比较两个城市/两个年龄组——人眼不擅长比较角度；
- 如果某类占比 < 2%，可以合并到“其他”，但要在注释说明。

## 3. 柱形图规则

- 比较不同年龄组/城市/品类时优先用柱形图；
- 水平柱形图适合类别名较长（如“生活用品及服务”）；
- 纵轴从 0 开始，不要截断；
- 每个柱标数值；单位写在轴标题或图注；
- 年龄组按自然顺序排列（18-24 → 25-34 → …），不要按数值大小打乱；
- 分组柱形图的组数 ≤ 6，系列 ≤ 5；超过就拆图；
- 不要用 3D、渐变、阴影堆叠。

## 4. 数据要求

最低字段：

```text
year,city,age_group,category,per_capita_expenditure,currency,data_type,source,note
```

要求：

- 每个“城市 × 年份 × 年龄组”包含完整品类；
- 分母明确：是“全市总消费”“该年龄组总消费”，还是“某品类总消费”；
- 百分比按未四舍五入数据计算，展示时保留一位小数；
- 模拟数据必须标注“模拟”；
- 年龄组定义必须写清（如 18-24 是否含 18/24）；
- 不要用“青年/中年”这种模糊标签替代具体年龄段。

## 5. 视觉规范

- 画布：1200×750 px（16:9 图表），留白 ≥ 60 px；
- 字体：中文 `SimHei` / `Microsoft YaHei`，数字可用 `Arial`；
- 颜色：同一张图 ≤ 6 个主色；颜色 + 文字标签双编码，不能只靠颜色；
- 标题：一句话说清“谁、什么、哪一年”；
- 副标题：写口径/分母；
- 图注：数据来源、模拟/真实、样本量、局限；
- 对比度：正文与背景 ≥ 4.5:1。

## 6. 常见错误

| 错误 | 为什么错 | 正确做法 |
|---|---|---|
| 8 类硬塞饼图 | 小 slices 看不清 | 合并“其他”或改用条形图 |
| 两个饼图比大小 | 人眼不擅长比角度 | 用并排条形图 |
| 柱形图纵轴不从 0 开始 | 夸大差异 | 从 0 开始 |
| 年龄组按数值排序 | 丢失生命周期顺序 | 按年龄段自然顺序 |
| 只写“占比”不写分母 | 读者不知道占谁的比 | 写“占该年龄组总消费” |
| 用 3D/阴影 | 扭曲比例 | 平面、直接 |
| 颜色太多 | 无法区分 | ≤6 主色 + 标签 |

## 7. 本 SKILL 的默认输出

当用户说“给我饼图和柱形图”时，默认生成：

1. `pie_city_structure.png`：该城市/年份的品类结构饼图；
2. `bar_age_share.png`：不同年龄人群的消费比重柱形图；
3. `bar_age_category.png`：不同年龄人群的品类结构分组柱形图；
4. `chart_summary.md`：图表口径、分母、数据表、局限。

如果用户只要两张图，生成 1 + 2；第 3 张按需生成。

## 8. 输出话术

> 饼图回答“这个城市的钱按品类怎么分”，柱形图回答“不同年龄人群谁占的消费比重更高”。两张图的分母不同：饼图的分母是全市总消费，柱形图的分母也是全市总消费；分组柱形图的分母是该年龄组总消费。
