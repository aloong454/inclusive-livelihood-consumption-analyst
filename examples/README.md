# 示例输出

这些文件由 `scripts/analyze_livelihood.py`、`analyze_global.py`、`make_charts.py` 和测试脚本生成，使用 `assets/` 中的**模拟数据**。

| 文件 | 说明 |
|---|---|
| `analysis_summary.md` | 中国八大类分析摘要 |
| `indicators.csv` | 各群体/年份的总量、占比、刚性支出、发展型支出 |
| `category_growth.csv` | 品类增速、贡献度、占比变化 |
| `analysis_data.json` | 给图表/前端用的结构化数据 |
| `global_analysis_summary.md` | 全球城市/PPP 分析摘要 |
| `charts/pie_city_structure.png` | 城市消费结构饼图 |
| `charts/bar_age_share.png` | 年龄组消费比重柱形图 |
| `charts/bar_age_category.png` | 年龄组品类结构分组柱形图 |
| `charts/chart_summary.md` | 图表口径、分母与数据表 |
| `test_results.json` | 20 项计算断言结果 |
| `rule_coverage.json` | 8 条规则文档覆盖检查结果 |

> 模拟数据仅用于方法演示，不代表任何地区/群体的真实情况。
