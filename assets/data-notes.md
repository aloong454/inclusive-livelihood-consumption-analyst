# 模拟数据说明

## 1. 为什么用模拟数据

课程项目拿不到机构级、可公开的普惠客群消费明细。为了演示“从数据到洞察”的完整链路，我们构造了一组**结构合理、可复现、明确标注**的模拟数据：

- 宏观背景使用国家统计局 2025 年真实数据；
- 案例部分使用模拟数据，用于演示分析流程；
- 所有图表和报告都标注“模拟数据，仅用于课堂演示”。

**模拟数据不能用于任何真实业务决策，也不能代表成都或任何地区的真实情况。**

## 2. 校准思路

模拟数据参考了以下公开结构：

- 2025 年全国居民人均消费支出 29,476 元，食品烟酒占 29.3%、居住占 21.7%、交通通信占 14.6%、教育文化娱乐占 11.8%、医疗保健占 8.7%；
- 2025 年城镇居民人均消费支出 35,869 元，农村居民 20,259 元；
- 2025 年居民人均服务性消费支出 13,602 元，占消费支出 46.1%；
- 教育文化娱乐、交通通信、其他用品及服务增速较快，食品、居住、医疗增速较慢。

在此基础上，对“新市民”做两点合理假设：

1. 青年蓝领的居住和食品占比更高，刚性支出压力更大；
2. 小微经营者的收入波动更大，交通通信和教育支出占比略高。

这些是**待验证的假设**，不是研究结论。

## 3. 数据结构

| 字段 | 说明 |
|---|---|
| year | 2024 / 2025 |
| city | 成都（案例城市） |
| group | 新市民·青年蓝领 / 新市民·小微经营者 / 城镇常住居民 |
| category | 八大类消费 |
| per_capita_expenditure | 人均支出（元/年） |
| sample_size | 模拟样本量 |
| data_type | 模拟 |
| source | 校准说明 |
| note | 使用限制 |

## 4. 关键校验

| 群体 | 2024 总支出 | 2025 总支出 | 2025 同比 | 2025 刚性支出占比 |
|---|---:|---:|---:|---:|
| 新市民·青年蓝领 | 24,800 | 26,100 | +5.2% | 57.2% |
| 新市民·小微经营者 | 31,200 | 32,300 | +3.5% | 52.3% |
| 城镇常住居民 | 36,500 | 37,800 | +3.6% | 50.7% |

- 每个群体每年的八大类之和等于总支出；
- 占比按未四舍五入数据计算，展示保留一位小数；
- 同比为名义增速，未剔除价格因素。

## 5. 如果换成真实数据

替换 `sample_consumption.csv` 时，保持字段不变，并补充：

- 数据来源与授权说明；
- 样本覆盖范围、抽样方法、权重；
- 是否有缺失值、异常值、口径变化；
- 数据脱敏与最小化处理记录；
- 合规/法务复核意见。

替换后重新运行：

```bash
python scripts/analyze_livelihood.py \
  --input assets/your_data.csv \
  --outdir outputs \
  --base-year 2024 \
  --compare-year 2025
```

## 5.1 年龄组与图表数据

`sample_age_groups.csv` 是成都 2025 年的模拟年龄组数据：

- 5 个年龄组：18-24、25-34、35-44、45-54、55 岁以上；
- 8 个品类；
- 含 `population` 字段，用于把“人均消费”加权成“年龄组总消费”；
- 没有 `population` 时，图表脚本会退化为“简单占比”，并明确标注“未按人口加权”。

真实数据替换时，必须确认：

- 年龄组边界（是否含端点）；
- 人口数是常住人口还是户籍人口；
- 每组样本量是否足够；
- 分母是全市总消费还是该年龄组总消费。

## 5.2 全球城市样例

`sample_global_cities.csv` 是柏林/新加坡/圣保罗的模拟数据，用于演示：

- COICOP-8 proxy 分类；
- 本币 + PPP 因子；
- 城市级数据与可比性等级 B。

它不能代表真实国家/城市统计；真实分析必须替换为 World Bank/OECD/Eurostat/国家统计机构的数据。

## 6. 使用限制

- 不得把模拟数据写成“成都真实统计”；
- 不得用模拟数据推断个人收入、信用或还款能力；
- 不得用模拟数据对外发布、招商或营销；
- 课堂展示时，图表和讲稿都要保留“模拟数据”标识。
